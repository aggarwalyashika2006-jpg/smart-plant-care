🌱 Cloud-Connected Smart Plant Care System

A cloud-connected smart plant monitoring and watering system that collects plant sensor data, processes watering conditions, stores readings in a cloud PostgreSQL database, and displays the information through a web dashboard.

📌 Project Overview

The Cloud-Connected Smart Plant Care System is designed to monitor the environmental conditions of a plant and provide a centralized dashboard for viewing sensor readings.

The system works with sensor readings such as:

💧 Soil Moisture

🌡️ Temperature

💨 Humidity

☀️ Light Level

🚰 Pump Status

The backend receives sensor data, evaluates the watering condition, stores readings, and makes the information available to the frontend dashboard through REST APIs.

✨ Key Features

Real-time-style plant sensor monitoring

Soil moisture-based watering logic

Automatic watering status evaluation

Pump status tracking

Sensor data storage

Cloud PostgreSQL database integration

REST API using FastAPI

Web-based monitoring dashboard

Cloud deployment using Render

Sensor data simulation for testing

Frontend and backend deployed separately

🔄 How the System Works

Sensor values are generated by the sensor/simulation layer.

The readings are sent to the FastAPI backend.

The backend validates and processes the incoming data.

Soil moisture conditions are evaluated to determine the watering requirement.

The reading is stored in the PostgreSQL database hosted through Supabase.

The frontend dashboard requests the latest information from the backend API.

The dashboard displays the plant's current environmental readings and pump status.

💧 Watering Logic

The system uses a configured soil-moisture threshold to determine when watering is required.

For example:

Soil Moisture < Threshold
        ↓
Watering Required
        ↓
Pump / Watering Process

The backend also reports the current watering mode and pump status.

🚀 Running the Project Locally

1. Clone the repository

git clone https://github.com/aggarwalyashika2006-jpg/smart-plant-care.git
cd smart-plant-care

2. Create a virtual environment

python -m venv .venv

3. Activate the virtual environment

.\.venv\Scripts\Activate.ps1

4. Install dependencies

pip install -r requirements.txt

5. Configure environment variables

Create a .env file in the project root and add the required database configuration.

DATABASE_URL=your_database_connection_string

Do not commit your .env file or database credentials to GitHub.

6. Start the FastAPI backend

uvicorn backend.app:app --reload --port 8000

The local backend will be available at:

http://127.0.0.1:8000

7. Open the frontend

Open:

frontend/index.html

in a browser, or use a local development server such as the VS Code Live Server extension if configured.
